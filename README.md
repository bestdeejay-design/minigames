# Рубеж 64

Оригинальная браузерная стратегия в реальном времени: одна человеческая экспедиция против компьютерной. Добывайте минералы, развивайте базу, обороняйтесь от всё более крупных волн и уничтожьте **все здания противника**. Поражение наступает, если потеряны все ваши здания.

**Игра:** корневой [`index.html`](./index.html). **Прежний каталог мини-игр:** [`catalog/`](./catalog/). Все 11 ранее опубликованных игр остались в своих папках.

## Управление

| Действие | Управление |
| --- | --- |
| Выделить юнита/здание; выделить отряд рамкой | ЛКМ; зажать ЛКМ и протянуть |
| Добавить юнита к выделению | Shift + ЛКМ |
| Движение, атака, добыча, достройка; точка сбора здания | ПКМ по соответствующей цели |
| Запомнить / выбрать отряд; центрировать камеру | Ctrl + 1–9 / 1–9; нажать номер дважды |
| Передвинуть камеру | Стрелки, указатель у края поля или клик/перетаскивание на миникарте |
| Жилой модуль / казарма (при выбранном инженере) | B / R, затем ЛКМ по освещённому свободному месту |
| Инженер из штаба / штурмовик из казармы | W / M; доступно при наличии минералов и свободного лимита |
| Добывать ближайшие минералы / остановиться | G / S |
| Атака с продвижением | A, затем ЛКМ по пункту назначения |
| Отменить размещение / поставить на паузу | Esc или ПКМ / пробел |

Инженеры начинают добычу автоматически и возобновляют её после окончания строительства. Для ручного выбора минерального узла выделите инженера и нажмите ПКМ на кристалле. Жилые модули увеличивают лимит населения, казармы обучают штурмовиков; штаб выпускает инженеров. Звук включается кнопкой вверху и синтезируется Web Audio **только после действия пользователя**. При переходе на другую вкладку игра автоматически ставится на паузу. Настройка звука и лучшее время хранятся на устройстве, если доступен `localStorage`.

## Запуск и публикация

Игра — чистый HTML/CSS/JavaScript с Canvas: **не нужны сборка, npm, бэкенд, CDN и внешние ассеты**. Все пути к модулям относительные и с расширением `.js`; во время игры нет запросов к сторонним сервисам. Для публикации на GitHub Pages:

1. В настройках репозитория откройте **Settings → Pages → Build and deployment**.
2. Выберите **Deploy from a branch**, ветку с игрой (`arena/6f24bc3f-minigames` для этой работы) и каталог **/(root)**. Если Pages уже публикует другую ветку, сначала перенесите изменения туда привычным для проекта способом.
3. После развёртывания откройте `https://bestdeejay-design.github.io/minigames/`; прежний каталог находится по адресу `/minigames/catalog/`. Пустой `.nojekyll` отключает обработку Jekyll.

Для локальной проверки ES-модулей откройте корень через любой **статический** HTTP-сервер, например `python3 -m http.server 8000`, затем `http://localhost:8000/`. Он нужен только для локального открытия модулей: браузеры обычно блокируют ES-модули по `file://`. На GitHub Pages ничего запускать не требуется.

## Устройство игры

- `js/config.js` — общие числовые параметры мира, юнитов, построек и правил.
- `js/map.js` — фиксированная карта 64 × 64, препятствия, минералы, кеши Canvas для ландшафта и миникарты.
- `js/pathfinding.js` — A* с повторно используемыми буферами, учётом непроходимых углов и ограничением числа поисков за шаг.
- `js/units.js`, `js/buildings.js` — приказы, движение, расхождение юнитов, добыча с доставкой, строительство, очереди обучения и снаряды.
- `js/fog.js` — три состояния тумана войны: не исследовано / исследовано / видно; невидимые вражеские юниты не показываются.
- `js/ai.js` — противник добывает и тратит те же минералы, строит базу, обучает войска и посылает нарастающие волны.
- `js/game.js`, `js/main.js` — состояние, победа/поражение, фиксированный шаг 30 Гц, `requestAnimationFrame` и пауза неактивной вкладки.
- `js/render.js`, `js/input.js`, `js/ui.js`, `js/audio.js` — отрисовка видимой области, мышь/клавиатура, HUD и синтез звуков.

## Проверка

Реализация проверена по этапам: (1) загрузка карты и меню; (2) выделение, движение, A* и приказы; (3) добыча и доставка; (4) постройка, supply и обучение; (5) бой и оба исхода; (6) состояния тумана и скрытие врага; (7) экономика ИИ и увеличение волн; (8) полный сценарий с победой, пауза/рестарт и нагрузка около 200 юнитов. В браузерном стресс-тесте с 200 дополнительными юнитами средняя отрисовка занимала около 1,5 мс на кадр, шаг логики — около 0,7 мс на тестовой машине; фактическая частота зависит от устройства.

Прежние мини-игры доступны через каталог и не требуют изменений для работы RTS.
