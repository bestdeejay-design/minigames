# ⚔️ Звёздный рубеж (Star Frontier RTS)

Классическая стратегия в реальном времени в духе StarCraft, целиком написанная
на чистом JavaScript (ES-модули, Canvas 2D, Web Audio) — **без сборки,
зависимостей и сетевых запросов**. Работает на GitHub Pages из статических файлов.

**Две расы и мятежники. Кампания из 15 миссий в трёх актах. Улучшения армии.**
**Техника до САУ. Медики и огнемётчики. Стелс-рейд без базы. Тултипы со справкой.**

> 🚀 Играть: https://bestdeejay-design.github.io/terran-rts/
> (также доступна в каталоге: https://bestdeejay-design.github.io/minigames/rts/)

---

## Сюжет в двух словах

2189 год. Корпорация **«Гелиос-Индастриз»** добывает эрг-кристаллы на красной
планете **Актан-4** — и не считает аборигенов разумными. А зря: кристаллорождённые
**кхарид** считают минеральные поля священными колыбелями выводка. Так на Звёздном
рубеже начинается война железа и роя. А посреди неё вырастает третья сила —
мятежники **«Красного флага»**, готовящие «Глушитель», который погасит
кристаллы для всех.

Полная история, досье фракций, все юниты/здания/улучшения и разборы миссий —
в [GAME_GUIDE.md](GAME_GUIDE.md); архитектура кампании — в [CAMPAIGN.md](CAMPAIGN.md).

## Запуск

Нужен любой статический сервер (ES-модули не работают с `file://`):

```bash
python3 -m http.server 8080
# откройте http://localhost:8080/
```

Никаких зависимостей, сборки и сети — только браузер.

## Управление

| Действие | Клавиши |
|---|---|
| Выделение / рамка | ЛКМ, ЛКМ-тянуть |
| Добавить к выделению | Shift + ЛКМ |
| Приказ (идти / добывать / атаковать / ремонтировать / в бункер) | ПКМ |
| Меню стройки | `B` → `Q W E R T Y U I` (8 зданий) |
| Производство юнитов | `Q` / `W` / `E` (у выделенного здания) |
| Исследования | `Q` / `W` / `E` / `R` (у выделенной лаборатории) |
| Выпустить гарнизон | `F` (при выделенном бункере) |
| Отряды | `Ctrl/Shift + 1…9` назначить, `1…9` выбрать |
| Стоп / Пауза | `S` / `P` |
| Камера | Стрелки или мышь у края экрана, клик по миникарте |

## Структура кода

```
index.html          — точка входа, оверлеи меню
style.css           — тёмный «металлический» интерфейс
js/
  config.js         — весь баланс и константы (правится без кода)
  missions.js       — кампания, брифинги, профили ИИ, прогресс
  game.js           — цикл партии, команды, победа/поражение
  map.js            — генератор карт (биомы, симметрия, связность)
  pathfinding.js    — A* 8 направлений + сглаживание
  units.js          — юниты/техника: приказы, движение, бой, ремонт
  buildings.js      — здания: стройка, производство, турели, бункеры
  ai.js             — ИИ противника (профили миссий, оборона)
  fog.js            — туман войны
  input.js          — мышь/клавиатура
  audio.js          — синтез звука (Web Audio, без файлов)
  ui.js             — панели, миникарта, меню, брифинги
```

## Тесты

Живая проверка мышью (Playwright, входит в инструментарий репозитория-разработки):

- `scripts/audit_rts.mjs` — 21 проверка управления: одиночный юнит, пачка
  рамкой, добыча, стройка, атака, точки сбора;
- `scripts/smoke_features.mjs` — 20 проверок контента: кампания, турели,
  ремонт, бункер, завод, оборона, фракция кхарид;
- `scripts/test_fixes_27j.mjs` — 13 регрессов: урон по базам, камера СКМ,
  компактное меню стройки;
- `scripts/test_content_v3.mjs` — 20 проверок версии 3.0: 15 карт кампании,
  стелс-миссия без базы, новые юниты, лаборатория и бонусы исследований,
  лечение медиком, очередь с таймером, тултипы;
- `scripts/check_rts.mjs` — статика: синтаксис, импорты/экспорты, запреты
  на сеть и абсолютные пути.
